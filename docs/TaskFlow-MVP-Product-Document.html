TaskFlow

A clean, manual task manager. Users register, log in, and organise their own tasks with priorities, due dates, reminders, groups, and drag-and-drop ordering. A separate CRM admin panel lets the team manage users.

1. What we are building

TaskFlow is a straightforward to-do application with real accounts. A user signs up with their email, logs in, and manages their own tasks. Nothing is shared with other users, and all data lives in our own MongoDB database — no external services.

Alongside it, we ship a CRM admin panel on a separate URL. That is for us, not for customers. Admins log in with a fixed admin account and can view, create, edit, and delete users and their activity.

Two apps, one database:
TaskFlow App (/) — public sign-up, normal users, their own tasks.
TaskFlow CRM (/crm) — admin login only, no registration, full visibility over users.

1.1 Important correction from v1.0

Version 1.0 described an AI agent that created and reorganised tasks. That is removed. Users create and manage everything manually. AI is used by us during development only, and is never part of the running product, the UI, or the database.

5. User journey (simple)

Register → Login → Dashboard (My Tasks) │ ┌───────────────┬───────┴────────┬──────────────┐ ▼ ▼ ▼ ▼ Add a task Set priority / Set reminder Group / sort / due date drag to reorder │ ▼ Complete or delete → Logout
  1. User opens the app, clicks Register, enters name, email, password.
  2. Registration completes and they are logged straight in (JWT cookie set).
  3. They land on My Tasks and add their first task.
  4. They can set priority, a due date, and optionally a reminder time.
  5. They organise tasks into groups, sort them, and drag to reorder.
  6. They complete tasks (checkbox), edit them, or delete them.
  7. Logout clears the session.

16. Definition of Done

  1. A visitor can register with their own email and is logged in immediately.
  2. Login, logout, and session-after-refresh all work using a JWT cookie.
  3. Two different users never see each other's tasks or groups.
  4. Tasks support create, edit, delete, complete/uncomplete, priority, and due date.
  5. Reminders can be set, edited, removed, and fire once in the app.
  6. Groups can be created and renamed; tasks can be moved between them.
  7. Tasks can be sorted and reordered by drag and drop, and the order persists.
  8. Filters (All, Active, Completed, Today, Overdue) and search work.
  9. CRM at /crm has admin-only login with no registration.
  10. CRM can list, create, edit, disable, and delete users, and view their tasks and activity.
  11. Seed script creates one admin and three demo users with sample data.
  12. README documents environment variables, how to run, and the demo credentials.
  13. No AI feature exists anywhere in the running product.
